# 智伴优程小程序图标清单与设计指令

## 设计风格说明

**整体风格**：Soft/Pastel + Luxury（柔和精致风）

**色彩规范**：

- 主色（选中态）：暖杏色 `#FF8066`
- 辅助色：蜜桃橙 `#FFAB91`
- 强调色：森林绿 `#2E7D6B`
- 成功色：薄荷绿 `#4DB6A0`
- 警告色：琥珀黄 `#FFB74D`
- 默认态：暖灰 `#A8A5A2`
- 背景填充：淡粉 `#FFE8E4`

**尺寸规范**：

- TabBar图标：81×81像素
- 导航/菜单图标：80×80像素
- 服务类型图标：88×88像素
- 消息类型图标：120×120像素

## 使用说明

1. 复制对应图标的 **Stitch设计指令** 到 [Google Stitch](https://stitch.withgoogle.com/)
2. 生成后下载PNG格式
3. 使用图片编辑工具裁切到指定尺寸
4. 运行 `python scripts/compress_icons.py` 压缩到40KB以下
5. 替换到对应的 `miniprogram/images/` 目录

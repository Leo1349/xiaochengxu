# 小程序提审与发布检查清单

## 1. 版本与记录
- [ ] 在微信开发者工具设置 `版本号` 与 `项目备注`
- [ ] 记录本次 Git 提交号与变更范围
- [ ] 确认 `appid`、云环境 `env` 使用生产配置

## 2. 上传前技术检查
- [ ] 本地编译无报错、无红色告警
- [ ] JS 语法检查通过（`node --check`）
- [ ] `app.json` 页面路由与实际文件一致
- [ ] 云函数代码已同步到最新版本

## 3. 云开发与数据检查
- [ ] 关键云函数已执行“上传并部署（云端安装依赖）”
- [ ] 数据库权限规则已核对（最小权限原则）
- [ ] 关键集合索引已建立（订单、用户、消息等高频查询字段）
- [ ] 云存储文件访问权限符合预期

## 4. 体验版回归（至少一轮）
- [ ] 登录/授权流程正常
- [ ] 首页加载（Banner、推荐数据）正常
- [ ] 下单链路正常（下单、查看订单、取消）
- [ ] 订单状态流转正常（确认、服务中、完成）
- [ ] 消息/反馈/客服页面可用
- [ ] 管理后台核心功能可用（登录、查询、状态更新）

## 5. 提审材料
- [ ] 更新说明明确、可复现
- [ ] 提供审核路径与测试账号（如需）
- [ ] 隐私协议、用户信息处理说明为最新
- [ ] 服务类目与资质材料齐全（如涉及）

## 6. 发布与回滚
- [ ] 审核通过后先灰度发布
- [ ] 观察错误日志、云函数失败率、核心转化数据
- [ ] 准备上一稳定版本号用于快速回滚

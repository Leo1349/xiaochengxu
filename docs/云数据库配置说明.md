# 云数据库配置说明

本文档记录了小程序中需要通过云数据库配置的内容及字段规则。

---

## 📌 轮播图配置（banners 集合）

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `image` | String | ✅ | 图片地址（云存储 FileID 或 https 链接） |
| `url` | String | ❌ | 点击跳转路径（如 `/pages/case-list/index`） |
| `isActive` | Boolean | ✅ | 是否显示（`true` 显示，`false` 隐藏） |
| `order` | Number | ✅ | 排序（数字越小越靠前，如 1, 2, 3） |

**示例记录：**

```json
{
  "image": "cloud://xxx/banner1.jpg",
  "url": "/pages/case-list/index",
  "isActive": true,
  "order": 1
}
```

---

## 📌 推荐陪伴师（teachers 集合）

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `name` | String | ✅ | 老师姓名 |
| `avatar` | String | ❌ | 头像地址 |
| `title` | String | ❌ | 头衔（如"金牌陪伴师"） |
| `rating` | Number | ❌ | 评分（如 4.9） |
| `orderCount` | Number | ❌ | 服务次数 |
| `tags` | Array | ❌ | 标签（如 ["学科辅导", "耐心细致"]） |
| `price` | Number | ❌ | 价格 |
| `priceUnit` | String | ❌ | 价格单位（如"小时"） |
| `isRecommended` | Boolean | ✅ | 是否在首页推荐显示 |

---

## 📌 用户数据（users 集合）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `_openid` | String | 微信 OpenID（自动生成） |
| `nickName` | String | 昵称 |
| `avatarUrl` | String | 头像 |
| `phone` | String | 手机号 |
| `currentRole` | String | 角色（parent/teacher） |
| `createTime` | Date | 创建时间 |
| `lastLoginTime` | Date | 最后登录时间 |

---

## ⚠️ 注意事项

1. **修改云函数后必须重新部署**：右键云函数文件夹 → "上传并部署：云端安装依赖"
2. **图片地址**：可以使用云存储的 FileID，也可以使用 https 开头的网络图片
3. **刷新生效**：修改数据库后，需要在小程序中下拉刷新页面
